# Eliminação de dados — SURVIVE

[Política de privacidade](../) · [Support](../support/)

## Português

A SURVIVE não cria uma conta online e o programador não possui uma cópia dos dados introduzidos. O perfil e os dados ficam apenas no dispositivo.

Para apagar o perfil e os dados associados:

1. abre a SURVIVE e desbloqueia o perfil;
2. abre **Perfil** no menu;
3. seleciona **Eliminar o meu perfil**;
4. confirma a eliminação.

Também podes apagar todos os dados em **Definições Android → Aplicações → SURVIVE → Armazenamento → Limpar dados**, ou desinstalar a app.

Os backups JSON exportados não são controlados pela SURVIVE. Apaga-os separadamente na aplicação Ficheiros ou no serviço onde decidiste guardá-los.

Como nenhum dado é enviado ao programador, não existe um pedido remoto de eliminação a processar. Para dúvidas, contacta [osvaldo@osvaldocipriano.dev](mailto:osvaldo@osvaldocipriano.dev).

## English

SURVIVE does not create an online account, and the developer does not hold a copy of data entered in the app. The local profile and its data remain only on the device.

To delete the profile and associated data:

1. open SURVIVE and unlock the local profile;
2. open **Profile** from the menu;
3. select **Delete my profile**;
4. confirm deletion.

You can also remove all data through **Android Settings → Apps → SURVIVE → Storage → Clear data**, or uninstall the app.

Exported JSON backups are not controlled by SURVIVE. Delete them separately from the Files app or the service where you chose to store them.

Because no data is sent to the developer, there is no remote deletion request to process. For questions, contact [osvaldo@osvaldocipriano.dev](mailto:osvaldo@osvaldocipriano.dev).
