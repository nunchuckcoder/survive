# Suporte — SURVIVE

[Política de privacidade](../) · [English privacy policy](../en/) · [Eliminar dados](../delete-data/)

Para ajuda com a SURVIVE, envia uma mensagem para:

**[osvaldo@osvaldocipriano.dev](mailto:osvaldo@osvaldocipriano.dev)**

Inclui, se possível:

- versão da aplicação;
- modelo do dispositivo e versão Android;
- idioma e tema usados;
- passos para reproduzir o problema;
- resultado esperado e observado.

Não envies passwords, backups, nomes de medicamentos, dados de menores ou outros dados pessoais/sensíveis. Antes de anexar uma captura de ecrã, remove ou oculta essas informações.

## Support in English

For help with SURVIVE, email **[osvaldo@osvaldocipriano.dev](mailto:osvaldo@osvaldocipriano.dev)** and include the app version, device model, Android version, language, theme, reproduction steps, expected result and actual result.

Do not send passwords, backups, medicine names, children's data or other personal/sensitive information. Remove or hide such information before attaching a screenshot.
